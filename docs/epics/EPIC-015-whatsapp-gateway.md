## Goal

Owner request 2026-08-09: link a WhatsApp account by scanning a QR in Admin,
then have the app deliver its existing WhatsApp notifications through it —
no Meta Business account, no per-message fees.

## Tasks

- [x] **T-150** Baileys session manager (singleton, persisted credentials,
  QR capture, auto-reconnect), admin panel with live QR + status + test send,
  transport wired into the existing notification fan-out, phone-number
  normalisation with unit tests.

## Acceptance Criteria

- Admin (`org.manage`) can link a device by scanning a QR; staff get 403.
- Credentials survive a redeploy — no re-scan after `docker compose up`.
- Notifications already routed to WhatsApp (assigned, due soon, overdue,
  approval requested/decided) deliver through the gateway to each
  recipient's own number, respecting their per-user WhatsApp opt-in.
- Local number formats (08xx) reach the right msisdn.
- Gateway offline = silent skip; no mutation ever fails because of WhatsApp.
